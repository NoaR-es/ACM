# US-22.03 — Ejecutar inferencia local · Refinamiento

Sprint: SPRINT-003

## Precondiciones
- Motor Ollama registrado (US-22.01).

## Flujo
1. Un consumidor (hoy, el contexto compacto) pide una generación al router con `purpose` y `project_id`.
2. El router la envía a `POST <url>/api/chat` con el modelo configurado, `stream: false` y `num_predict` = `max_output_tokens`.
3. La respuesta se registra en `inference_calls` (motor, tokens de entrada y salida, duración) y el router devuelve su `call_id`.

## Alternativas
- Si hay varios motores de generación, el siguiente atiende cuando uno falla, y la respuesta lo indica en `fallback_from`.

## Errores
- Runtime caído o HTTP ≠ 200 (incluido el 404 de modelo inexistente) → `ENGINE_UNAVAILABLE` y llamada registrada con `status = error`.
- Respuesta sin `done: true`, con contenido vacío o que no es un objeto JSON → `ENGINE_ERROR`: no se declara éxito.

## Reglas
- Los consumidores no llaman a Ollama: usan `EngineRouter.generate` (ADR-015).

## Validaciones
- `max_output_tokens` lo fija el consumidor.

## Casos límite
- **Pendiente:** verificación contra un Ollama real (SPIKE-005).
