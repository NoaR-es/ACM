# US-14.05 — Descubrir las herramientas MCP disponibles · Refinamiento

Sprint: SPRINT-002

Origen B:US-15.02 sin criterios: se definen aquí.

## Criterios de aceptación
- CA-01: `tools/list` devuelve todas las herramientas de ACM, cada una con esquema de entrada.
- CA-02: Ninguna herramienta tiene descripción vacía.
- CA-03: Las herramientas que actúan sobre un proyecto declaran `project_id` como obligatorio en su esquema.

## Precondiciones
- Conexión MCP establecida.

## Flujo
1. El agente llama a `tools/list`.
2. Recibe nombre, descripción y esquema JSON de cada herramienta.

## Alternativas
- El agente también puede leer la skill `acm-schema`, que documenta las mismas herramientas.

## Errores
- Ninguno específico.

## Reglas
- La lista de herramientas documentada en `acm-schema` debe coincidir con la del servidor (US-15.08).

## Validaciones
- El test compara el conjunto de herramientas con el esperado.

## Casos límite
- Herramientas solo para admin (`acm_audit_list`, `acm_skills_reload`) aparecen en la lista y se rechazan al invocarlas sin permiso.
