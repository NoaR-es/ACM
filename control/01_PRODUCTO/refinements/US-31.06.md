# US-31.06 — Revisar todo desde la interfaz · Refinamiento

Sprint: SPRINT-007

## Precondiciones
- Sesión iniciada en la interfaz con un token `acm_` válido (US-31.01, ADR-017).

## Flujo
1. El operador abre un proyecto: resumen, backlog (requisitos, épicas, features, historias, CA), trazabilidad, Kanban, gobernanza, miembros y configuración.
2. Desde una historia navega a épica, feature, requisitos y criterios.
3. «Documentación» muestra skills, flujo de estados y referencia de la API (OpenAPI).
4. «Sistema» muestra salud, motores, ahorro, principales y tokens (admin).

## Alternativas
- Usuario no admin: sin vistas de sistema; la API responde 403 si se fuerzan.

## Errores
- `NOT_FOUND` para proyectos ajenos (no se revela su existencia).

## Reglas
- La interfaz solo muestra lo que la API autoriza (ocultar enlaces es comodidad, no seguridad).
