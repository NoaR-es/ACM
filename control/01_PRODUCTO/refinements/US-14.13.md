# US-14.13 — Recibir las skills y el proceso por la vía MCP que soporte el cliente · Refinamiento

Sprint: SPRINT-009

## Precondiciones
- Agente conectado a ACM por MCP.

## Flujo
1. En la inicialización el agente recibe unas `instructions` breves: qué es ACM, cómo obtener la skill `acm-workflow` y por dónde empezar.
2. El agente lee la skill por la vía que su cliente soporte: herramienta `acm_skill_get`, recurso `skill://…`, prompt MCP `acm-workflow` / `acm-skill` o la extensión de skills.
3. Sigue el proceso de `acm-workflow`.

## Alternativas
- Cliente sin recursos ni prompts: usa las herramientas (todos las soportan).

## Errores
- Skill inexistente: `NOT_FOUND` por herramienta, error `-32602` por la extensión y por prompt.

## Reglas
- Las `instructions` no repiten el contenido de las skills (se cargan siempre y costarían tokens); el texto completo solo se entrega bajo demanda.
- Una sola fuente: el mismo archivo `SKILL.md` por todas las vías.

## Validaciones
- `instructions` < 1500 caracteres.
- `acm-workflow` solo cita herramientas que existen.

## Casos límite
- Cada lectura de una skill queda en la auditoría (`prompts/get`, `resources/read`, `skills/get`).
