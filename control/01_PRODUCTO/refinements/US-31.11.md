# US-31.11 — Gestionar el acceso desde la interfaz · Refinamiento

Sprint: SPRINT-008

## Precondiciones
- Sesión iniciada en la interfaz o agente con token `acm_` (ADR-017).
- Admin (principales, tokens) u owner/admin (miembros).

## Flujo
1. Sistema → «+ Nuevo principal» y selector de rol global.
2. Proyecto → Miembros: añadir, cambiar rol, retirar.
3. Sistema → «+ Nuevo token»: el secreto se muestra una vez con «Copiar»; «Revocar» lo invalida.

## Alternativas
- Un principal puede revocar sus propios tokens.

## Errores
- Rol sin permiso: `FORBIDDEN`.

## Reglas
- El secreto nunca se audita ni se vuelve a mostrar (ADR-017).
