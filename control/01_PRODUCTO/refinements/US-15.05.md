# US-15.05 — Descargar todas las skills desde el servidor MCP · Refinamiento

Sprint: SPRINT-002

## Precondiciones
- Conexión MCP.

## Flujo
1. Por cada recurso de `skills/list`, el agente llama a `resources/read(uri)`.
2. Verifica el digest.
3. `skills/get(uri)` devuelve la entrada de una skill.

## Alternativas
- `acm_skill_get(name)` devuelve todos los archivos de la skill en una llamada.

## Errores
- `skills/get` de una skill inexistente → `-32602`.
- `resources/read` de una URI inexistente → error de recurso no encontrado.

## Reglas
- Los archivos se sirven con una plantilla `skill://acm/{skill}/{filename}` que consulta el catálogo vigente: una skill retirada deja de ser legible (US-15.07 CA-02).

## Casos límite
- Skill con varios archivos: todos legibles y listados.
