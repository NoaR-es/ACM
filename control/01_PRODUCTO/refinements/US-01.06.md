# US-01.06 — El agente conoce el proyecto antes de ejecutar una herramienta · Refinamiento

Sprint: SPRINT-001

Origen: B:US-01.03 ("Como agente quiero conocer el proyecto activo antes de ejecutar una herramienta para evitar modificar otro proyecto"). La fuente no traía criterios (GAP-001): se definen aquí.

## Criterios de aceptación
- CA-01: Toda herramienta MCP que opera sobre un proyecto exige el parámetro `project_id`; sin él, la llamada se rechaza antes de ejecutar nada.
- CA-02: Toda respuesta de una herramienta de proyecto incluye el `project_id` sobre el que actuó.
- CA-03: Un `project_id` inexistente o no accesible produce un error explícito (`NOT_FOUND`) con el motivo legible por el agente, y no modifica ningún proyecto.
- CA-04: Las `instructions` del servidor MCP indican al agente que debe pasar `project_id` en cada llamada y cómo obtenerlo (`acm_project_list`).

## Precondiciones
- El agente está conectado al servidor MCP de ACM (Streamable HTTP o stdio).

## Flujo
1. Al conectar, el agente recibe `instructions` que explican el uso de `project_id`.
2. Llama a `acm_project_list` y elige un `project_id`.
3. Pasa ese `project_id` en cada herramienta de proyecto.
4. Cada respuesta repite el `project_id` para que el agente confirme sobre qué proyecto actuó.

## Alternativas
- Herramientas sin proyecto (`acm_project_list`, `acm_project_create`, `acm_system_info`) no llevan `project_id`.

## Errores
- Falta `project_id` → error de validación de argumentos del SDK (esquema de la herramienta).
- `project_id` desconocido → `NOT_FOUND: project_id '<x>' no existe o no es accesible`.

## Reglas
- No existe "proyecto activo" en el servidor (ADR-014). La fuente de verdad del proyecto de una operación es el argumento `project_id`.
- Los errores de dominio llegan al agente con código y mensaje (mitigación de GAP-007).

## Validaciones
- El esquema JSON de cada herramienta de proyecto declara `project_id` como obligatorio.

## Casos límite
- `project_id` con mayúsculas o espacios → `INVALID_ARGUMENT`, sin intentar normalizar.
- Dos agentes concurrentes con distintos `project_id` no se interfieren (no hay estado compartido de selección).
